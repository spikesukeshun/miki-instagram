# リール用の撮影ガイド（MIKIさん向け）

写真を並べるのではなく、実際の映像でリールを作るためのお願いです。
LINEで送る時は、この内容をそのまま使えます。

## 撮り方の基本

- **スマホは縦向き**で撮ってください
- **iPhoneの「HDRビデオ」はオフ**にしてください（設定 ＞ カメラ ＞ ビデオ撮影 ＞ HDRビデオ）
  - オンのままだと、編集したときに色が崩れることがあります
- **1本は5〜15秒**くらいで十分です。長く回しっぱなしでも大丈夫です
- 同じ場面を**2回ずつ**撮ってもらえると、良い方を選べます
- 撮り始めと撮り終わりの1秒は使わないので、少し長めに回してください
- **編集アプリ（InShotなど）で書き出さず、撮ったままの動画**をアップロードしてください
  - 書き出すと透かしが入ったり、画面の左右にぼかしが入ったりして使いにくくなります
- 話し声や物音は気にしなくて大丈夫です（あとで消せます）

## 撮ってほしい映像の例

| 場面 | 例 | ポイント |
|---|---|---|
| 施術の手元 | 背中・脚・フェイスのトリートメント | 手の動きが分かる近さで。お客様の顔は写さない |
| 準備 | オイルを手に取る・タオルを整える・マシンの準備 | 手元のアップ |
| 店内 | 入口・施術室・ジャグジー | ゆっくり横に動かすか、止めて撮る |
| カウンセリング | 手元・メモ・話している様子 | お客様の顔は写さない |
| 商品 | 手に取る・使ってみせる | 商品名が読める向きで |
| MIKIさん本人 | あいさつ・笑顔・歩いてくる | 正面・横からの両方 |

## お客様が写る場合

- 顔が写らないように撮ってください（背中・手足・うしろ姿など）
- 投稿に使ってよいか、お客様に同意をもらってください
- **ビフォーアフター**に使う場合は、書面での同意と「いつ・どの部位に・何の施術をしたか」を残してください
  （分からないものは投稿に使いません）

## アップロード先

動画は Googleドライブ「instagram投稿素材 ＞ **動画**」フォルダに入れてください
（今ある動画と同じ場所です。受け取り場所を増やさないため、撮影分もここに入れてください）。
写真やその他のファイルは「リール素材 ＞ 01_動画・写真の受付」へ。

- iPhoneのGoogleドライブアプリ ＞ フォルダを開く ＞ ＋ ＞ アップロード
- ファイル名は変えなくて大丈夫です
